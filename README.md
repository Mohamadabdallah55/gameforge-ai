# GameForge AI — Elite Intelligence

ورشة عربية لإنتاج حزم أسئلة المسابقات. لكل لعبة قواعد صياغة وأسماء حقول ومكتبة أسئلة. يمكن مشاركة الصور بين الألعاب. التطبيق لمستخدم واحد ويعمل بخادم Node واحد.

## التشغيل المحلي

استخدم Node.js 24 وnpm. شغّل `npm ci` ثم `npm run local` من جذر المستودع وافتح http://127.0.0.1:3000. تعمل المكتبة والتصدير والوسائط المحلية دون مفتاح. يبدأ إنتاج الأسئلة عند تهيئة `GEMINI_API_KEY` من مشروع Gemini API على Free Tier دون فاتورة، وضبط `GEMINI_FREE_PROJECT_CONFIRMED=1` بعد التحقق من المشروع. يحفظ المفتاح في `.env` المحلي أو أسرار الخادم. للحصول على مسارات المحركات والنماذج وأوامر التحقق، راجع [دليل التشغيل المحلي](LOCAL_SETUP.md).

## دورة إنتاج

1. من «ملفات الألعاب» ارفع نموذج JSON أو CSV أو XLSX، راجع ربط الحقول، واكتب قواعد اللعبة واحفظها. يمكنك أيضًا البدء باللعبة الافتراضية.
2. من «الإنتاج» اكتب طلبًا بالعربية واضغط «بدء مهمة إنتاج». تستطيع ضبط المستويات 200 و400 و600 ونسب الصور وأنواعها يدويًا.
3. ابدأ المهمة. يثبت العامل كل سؤال مقبول فورًا. إذا توقفت المهمة، صحح السبب ثم اضغط استئناف. عدد الصور المستهدف هو أقرب عدد صحيح للنسبة المطلوبة من الإجمالي.
4. راجع السؤال ودليل الإجابة وصورته في «المكتبة». من Media Lab ارفع أصلًا مسموحًا، حرره عبر ComfyUI أو Sharp أو Apple Vision، وقارن النسخ واحفظ ما يناسبك. تستطيع استخراج إطار من فيديو مصرح به وربط الأصل أو إحدى نسخه بالسؤال.
5. نزّل ZIP لنقل الأسئلة مع الصور ونسبتها إلى أصحابها. تستخدم ملفات JSON وCSV وExcel المنفردة نفس مسارات الصور النسبية. ضع مجلد images من أرشيف اللعبة بجانبها.

[تسعير Gemini API الرسمي](https://ai.google.dev/gemini-api/docs/pricing) · [حدود المشروع الفعلية في AI Studio](https://aistudio.google.com/usage?tab=rate-limit)

## التشغيل والاختبارات

```sh
npm test
npm run build
npm start
```

للتحقق من الواجهة بعد البناء، شغّل `npx playwright install chromium` ثم `npm run test:ui`. إذا كان Google Chrome مثبتًا يمكنك استخدام `CHROME_CHANNEL=chrome npm run test:ui`. يستخدم الاختبار قاعدة مؤقتة خاصة به.

توجد الأسئلة والصور وحالة المهام في DATA_DIR (الافتراضي data). خذ نسخة من المجلد بعد إيقاف الخادم لاستعادة المكتبة. يحتاج التشغيل المستضاف إلى قرص دائم لحفظ العمل عبر استبدال الحاوية.
