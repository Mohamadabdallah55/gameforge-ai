# GameForge AI

ورشة عربية لإنتاج حزم أسئلة المسابقات. لكل لعبة قواعد صياغة وأسماء حقول ومكتبة أسئلة. يمكن مشاركة الصور بين الألعاب. التطبيق لمستخدم واحد ويعمل بخادم Node واحد.

## التشغيل

استخدم Node.js 24 (اختُبر 24.22.1) وnpm. شغّل من المجلد المحتوي على package.json.

```sh
npm ci
cp .env.example .env
npm run dev
```

افتح http://127.0.0.1:3000. أدخل مفتاحك في GEMINI_API_KEY داخل .env لتفسير الطلب العربي وتوليد الأسئلة والتضمينات والصور وتعديلها. المفاتيح وأسماء النماذج تُقرأ في الخادم عند التشغيل. أعد تشغيله بعد التعديل. تأكد من إتاحة النماذج الثلاثة لحسابك. ينقلك TAVILY_API_KEY الاختياري إلى البحث العام على الويب. البحث الافتراضي في ويكيبيديا وCommons يعمل بلا مفتاح.

## دورة إنتاج

1. من «ملفات الألعاب» ارفع نموذج JSON أو CSV أو XLSX، راجع ربط الحقول، واكتب قواعد اللعبة واحفظها. يمكنك أيضًا البدء باللعبة الافتراضية.
2. من «الإنتاج» اكتب طلبًا مثل «أريد ٣ سهلة و٢ متوسطة وسؤالًا صعبًا عن كأس العالم ٢٠٢٢، نصفها بصور». حلّل الطلب ثم راجع الأعداد. تستطيع ملء الخطة يدويًا.
3. ابدأ المهمة. يثبت العامل كل سؤال مقبول فورًا. إذا توقفت المهمة، صحح السبب ثم اضغط استئناف. عدد الصور المستهدف هو أقرب عدد صحيح للنسبة المطلوبة من الإجمالي.
4. راجع السؤال ودليل الإجابة وصورته في «المكتبة». من «الوسائط» يمكنك رفع صورة أو اختيار ثانية من فيديو مصرح به، تطبيق تأثير محلي أو طلب تعديل من Gemini. اربط الصورة الناتجة بأي سؤال من مكتبته.
5. نزّل ZIP لنقل الأسئلة مع الصور ونسبتها إلى أصحابها. تستخدم ملفات JSON وCSV وExcel المنفردة نفس مسارات الصور النسبية. ضع مجلد images من أرشيف اللعبة بجانبها.

## التشغيل والاختبارات

```sh
npm test
npm run build
npm start
```

للتحقق من الواجهة بعد البناء، شغّل `npx playwright install chromium` ثم `npm run test:ui`. إذا كان Google Chrome مثبتًا يمكنك استخدام `CHROME_CHANNEL=chrome npm run test:ui`. يستخدم الاختبار قاعدة مؤقتة خاصة به.

توجد الأسئلة والصور وحالة المهام في DATA_DIR (الافتراضي data). خذ نسخة من المجلد بعد إيقاف الخادم لاستعادة المكتبة. يحتاج التشغيل المستضاف إلى قرص دائم لحفظ العمل عبر استبدال الحاوية.
